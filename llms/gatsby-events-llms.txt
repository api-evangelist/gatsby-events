# Gatsby Help Center

> Gatsby is an event management platform for professional gatherings (corporate events, AGMs, galas) that combines CRM with event tools. Core structure: Contacts (people database) → Events (date-specific gatherings) or Lists (ongoing groups) → Tools (Guest List, RSVP/Landing Pages, Email Campaigns, Seating Charts, Check-In). Events use personal RSVP links (unique per guest) or public links (open registration). Guests register via landing pages, receive confirmation emails with calendar invites, and are tracked through RSVP statuses (Invited, Clicked, Accepted, Declined, Waitlisted). The platform handles the complete event lifecycle: planning, invitations, registration, check-in, and follow-up. Integrates with Gmail/Outlook/SendGrid for email, Salesforce/Affinity for CRM, and supports parent-child event relationships for multi-session conferences.
